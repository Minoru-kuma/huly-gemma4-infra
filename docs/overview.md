# プロジェクト概要 — huly-gemma4-infra

## 背景

近年、大規模言語モデル（LLM）をプロジェクト管理ツールと統合し、タスク自動分類・要約・優先度付けを行う需要が高まっています。本プロジェクトでは、オープンソースのプロジェクト管理ツール **Huly** と Google DeepMind が開発した軽量 LLM **Gemma 4** を、自前の GPU クラスター（Slurm）上で連携させることを目標とします。

## 主要コンポーネント

### Gemma 4（LLM）

- Google DeepMind 製の軽量オープン LLM
- Ollama 経由で REST API として提供
- Slurm の GPU ノードでジョブとして実行

### Huly（プロジェクト管理）

- GitHub Issues / Linear 相当のオープンソース PM ツール
- Docker Compose で GPU ノード上にデプロイ
- Gemma 4 API と連携してタスク自動処理を行う予定

### Ollama

- LLM をローカルで動かすためのランタイム
- `localhost:11434` で REST API を提供
- Gemma 4 の GGUF モデルを管理・実行
